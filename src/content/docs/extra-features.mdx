---
title: Extra Features
description: Fork-only additions available in OpenTubeX.
---

OpenTubeX is a fork in its early stages that adds extra features beyond the
original project. Here is what’s unique so far.

## Per-channel playback speed

Remember playback speed on a per-channel basis. You can enable it in settings,
save automatically when you change speed, or use a button under the player to
save manually.

![Per-channel playback speed settings](https://github.com/user-attachments/assets/e8fe58f3-80f0-4280-946e-abf997f0eac3)
![Manual save button under player](https://github.com/user-attachments/assets/8fb28196-cf5a-4bb8-baa5-b911cb37262f)
![Per-channel speed indicator](https://github.com/user-attachments/assets/560a55c0-f653-4c21-ae30-5cdeff6ac428)

## Per-channel video quality

Remember video quality on a per-channel basis with the same workflow as
per-channel playback speed.

## Optional seek-interval behavior

Choose whether seek intervals (arrow keys and J/L) are multiplied by playback
rate.

![Seek interval setting](https://github.com/user-attachments/assets/9195f70e-a881-4052-b199-bbdad043e39a)

## Playback-rate adjusted timestamps

Optionally show timestamps adjusted for the current playback rate.

![Playback-rate adjusted timestamps setting](https://github.com/user-attachments/assets/d4d3cb45-b227-4521-a88b-2ff14051d0a6)
![Playback-rate adjusted timestamps example](https://github.com/user-attachments/assets/982ef08a-7f53-4efb-9ebc-c49328e306b9)

## Chapter tooltips on seekbar

Display chapter tooltips directly on the seekbar.

![Chapter tooltips on seekbar](https://github.com/user-attachments/assets/c6bed647-e872-458d-a4d6-2be58f4c17a0)

## Prevent YouTube translations

Option to prevent title and description translations from YouTube.

![Prevent title and description translations](https://github.com/user-attachments/assets/4713b8eb-9933-45cb-81ca-8db950ebec71)

## Quick search focus

Focus the search bar by pressing `/`, in addition to Ctrl+L or Cmd+L.

## SponsorBlock auto-skip toggle

Quickly toggle SponsorBlock auto-skip right under the player.

![SponsorBlock auto-skip toggle](https://github.com/user-attachments/assets/d5f300c7-8ba3-400d-ad21-1491638c348d)

## SponsorBlock tooltips (unskip / reskip)

Improved SponsorBlock tooltips with unskip and reskip when you need to replay or skip a segment again.

![SponsorBlock tooltip unskip](https://github.com/user-attachments/assets/299af609-e7f7-4b0d-802e-4062009fc77c)
![SponsorBlock tooltip reskip](https://github.com/user-attachments/assets/260874ac-1577-4f37-aa32-3b9a830e6d13)

## SponsorBlock community chapters

Display SponsorBlock community-contributed chapters in the player.

## Experimental tab support

Tabs are available in an early, work-in-progress state.

![Experimental tab support](https://github.com/user-attachments/assets/2ddbedea-5997-4a3c-af9e-6a36d3a21d04)

## IP block recovery script

Set a script to run when YouTube blocks your IP. OpenTubeX waits for the script to finish, then reloads the video.

![IP block recovery script setting](https://github.com/user-attachments/assets/2946401c-8e01-4048-9638-621289e31956)

## Auto Picture-in-Picture

Automatically enter Picture-in-Picture when you switch tabs or scroll away from a video.

![Auto Picture-in-Picture](https://github.com/user-attachments/assets/acb02ab5-2d9b-4e03-9c63-5f3988e2ddcb)
