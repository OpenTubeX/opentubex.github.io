## Package managers

On Windows, install OpenTubeX with [winget](https://learn.microsoft.com/windows/package-manager/winget/):

```powershell
winget install OpenTubeX.OpenTubeX
```

On Arch Linux, install from the AUR with a helper such as [paru](https://github.com/Morganamilo/paru) or [yay](https://github.com/Jguer/yay). Pick `opentubex-bin` for the prebuilt binary (faster to install) or `opentubex` to compile from source:

<Tabs syncKey="aur-helper">
	<TabItem label="paru">

		```sh
		# Prebuilt binary
		paru -S opentubex-bin

		# Build from source
		paru -S opentubex
		```

	</TabItem>
	<TabItem label="yay">

		```sh
		# Prebuilt binary
		yay -S opentubex-bin

		# Build from source
		yay -S opentubex
		```

	</TabItem>
</Tabs>

## Automated builds

Use these pre-release builds at your own risk.

- [GitHub Actions builds](https://github.com/OpenTubeX/OpenTubeX/actions/workflows/build.yml)
- [AUR (opentubex-git)](https://aur.archlinux.org/packages/opentubex-git/)

> You need a GitHub account to download builds from GitHub Actions.
> If you don't have one, you can use [nightly.link](https://nightly.link/OpenTubeX/OpenTubeX/workflows/build/development).
