## Package managers

### <span style="display: inline-flex; align-items: center; gap: 0.5rem;"><Icon name="simple-icons:windows" aria-hidden="true" /> Windows</span>

Install OpenTubeX with [winget](https://learn.microsoft.com/windows/package-manager/winget/):

```powershell
winget install OpenTubeX.OpenTubeX
```

### <span style="display: inline-flex; align-items: center; gap: 0.5rem;"><Icon name="simple-icons:ubuntu" aria-hidden="true" /> Debian / Ubuntu</span>

Add the signed [OpenTubeX APT repository](https://apt.opentubex.org) and install the package:

```sh
sudo install -d -m 0755 /etc/apt/keyrings
wget -qO- https://apt.opentubex.org/opentubex-archive-keyring.gpg \
  | sudo tee /etc/apt/keyrings/opentubex-archive-keyring.gpg >/dev/null
echo "deb [signed-by=/etc/apt/keyrings/opentubex-archive-keyring.gpg] https://apt.opentubex.org stable main" \
  | sudo tee /etc/apt/sources.list.d/opentubex.list >/dev/null
sudo apt update
sudo apt install opentubex
```

### <span style="display: inline-flex; align-items: center; gap: 0.5rem;"><Icon name="simple-icons:fedora" aria-hidden="true" /> Fedora / Red Hat</span>

Install from the official [OpenTubeX COPR repository](https://copr.fedorainfracloud.org/coprs/d3sox/opentubex/):

```sh
sudo dnf copr enable d3sox/opentubex
sudo dnf install opentubex
```

Alternatively, add the signed [OpenTubeX-hosted RPM repository](https://rpm.opentubex.org):

```sh
sudo curl --fail --location \
  --output /etc/yum.repos.d/opentubex.repo \
  https://rpm.opentubex.org/opentubex.repo
sudo dnf install opentubex
```

### <span style="display: inline-flex; align-items: center; gap: 0.5rem;"><Icon name="simple-icons:opensuse" aria-hidden="true" /> openSUSE</span>

Add the signed [OpenTubeX-hosted RPM repository](https://rpm.opentubex.org) and install OpenTubeX:

```sh
sudo rpm --import \
  https://rpm.opentubex.org/opensuse/repodata/repomd.xml.key
sudo zypper addrepo --refresh \
  https://rpm.opentubex.org/opensuse/ \
  opentubex
sudo zypper install opentubex
```

### <span style="display: inline-flex; align-items: center; gap: 0.5rem;"><Icon name="simple-icons:flatpak" aria-hidden="true" /> Flatpak</span>

Add the [OpenTubeX Flatpak remote](https://flatpak.opentubex.org) and install the package:

```sh
flatpak remote-add --if-not-exists opentubex \
  https://flatpak.opentubex.org/opentubex.flatpakrepo
flatpak install opentubex org.opentubex.OpenTubeX
```

### <span style="display: inline-flex; align-items: center; gap: 0.5rem;"><Icon name="simple-icons:archlinux" aria-hidden="true" /> Arch Linux</span>

Install from the AUR with a helper such as [paru](https://github.com/Morganamilo/paru) or [yay](https://github.com/Jguer/yay). Pick `opentubex-bin` for the prebuilt binary (faster to install) or `opentubex` to compile from source:

		```sh title="Build from source"

	</TabItem>
	<TabItem label="yay">

		```

## Development builds

Development builds provide early access to changes on the `development`
branch in two different ways:

| Automated builds | Nightly package channels |
| --- | --- |
| After development changes are pushed | Every day at 02:15 UTC |

<Aside type="caution" title="Development builds">
	Both options may contain unfinished features or regressions. Nightly channels
	are kept separate from stable repositories, but switching channels can
	replace an existing stable installation.
</Aside>

### Automated builds

The latest development artifacts are available from the
[Build workflow](https://github.com/OpenTubeX/OpenTubeX/actions/workflows/build.yml)
or through [nightly.link](https://nightly.link/OpenTubeX/OpenTubeX/workflows/build/development)
without a GitHub account.

Arch Linux users can build the current development revision with
[`opentubex-git`](https://aur.archlinux.org/packages/opentubex-git):

<Tabs syncKey="aur-helper">
	<TabItem label="paru">

		```sh title="Automated build"
		paru -S opentubex-git
		```

	</TabItem>
	<TabItem label="yay">

		```sh title="Automated build"
		yay -S opentubex-git
		```

	</TabItem>
</Tabs>

### Nightly package channels

<Tabs syncKey="nightly-platform">
	<TabItem label="Debian / Ubuntu">

		Add the signing key and select the `nightly` APT suite:

		```sh
		sudo install -d -m 0755 /etc/apt/keyrings
		wget -qO- https://apt.opentubex.org/opentubex-archive-keyring.gpg \
		  | sudo tee /etc/apt/keyrings/opentubex-archive-keyring.gpg >/dev/null
		echo "deb [signed-by=/etc/apt/keyrings/opentubex-archive-keyring.gpg] https://apt.opentubex.org nightly main" \
		  | sudo tee /etc/apt/sources.list.d/opentubex.list >/dev/null
		sudo apt update
		sudo apt install opentubex
		```

	</TabItem>
	<TabItem label="Fedora / Red Hat">

		Install the OpenTubeX nightly repository configuration:

		```sh
		sudo curl --fail --location \
		  --output /etc/yum.repos.d/opentubex-nightly.repo \
		  https://rpm.opentubex.org/opentubex-nightly.repo
		sudo dnf install opentubex
		```

	</TabItem>
	<TabItem label="openSUSE">

		Import the signing key and add the nightly RPM repository:

		```sh
		sudo rpm --import \
		  https://rpm.opentubex.org/opensuse/nightly/repodata/repomd.xml.key
		sudo zypper addrepo --refresh \
		  https://rpm.opentubex.org/opensuse/nightly/ \
		  opentubex-nightly
		sudo zypper install opentubex
		```

	</TabItem>
	<TabItem label="Flatpak">

		Add the OpenTubeX remote and install its nightly branch:

		```sh
		flatpak remote-add --if-not-exists opentubex \
		  https://flatpak.opentubex.org/opentubex.flatpakrepo
		flatpak install opentubex org.opentubex.OpenTubeX//nightly
		```

	</TabItem>
</Tabs>
