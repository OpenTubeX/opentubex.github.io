Development builds

Section titled “Development builds”

Development builds provide early access to changes on the development branch in two different ways:

Automated builds Nightly package channels
After development changes are pushed Every day at 02:15 UTC

Development builds

Both options may contain unfinished features or regressions. Nightly channels are kept separate from stable repositories, but switching channels can replace an existing stable installation.

Automated builds

Section titled “Automated builds”

The latest development artifacts are available from the Build workflow or through nightly.link without a GitHub account.

Arch Linux users can build the current development revision with opentubex-git:

  • paru
  • yay
