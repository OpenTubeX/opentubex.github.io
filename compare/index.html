No proprietary libraries

OpenTubeX · No proprietary libraries

No proprietary runtime SDK is declared in the checked app dependencies. Android explicitly excludes the unused proprietary ML Kit barcode scanner and uses ZXing for pairing. See the Android dependencies. Operating-system components and remote YouTube services are outside this comparison.

Source

FreeTube · No proprietary libraries

The official desktop app declares open-source dependencies, including Electron and its playback and extraction libraries. No proprietary runtime SDK is declared. This does not cover unofficial mobile forks, operating-system components, or remote YouTube services.

Source

Grayjay · No proprietary libraries

Android declares Stripe Android 22.0.0. Its payment module depends on Google's proprietary Play services Wallet client library. Stripe itself is open source. This payment dependency does not establish that ordinary video playback requires Play services; the separate desktop app has a different dependency stack.

Source

NewPipe · No proprietary libraries

NewPipe explicitly avoids proprietary libraries and frameworks such as Google Play services. Playback still contacts the selected media service; this is not a claim that YouTube itself is open source.

Source

LibreTube · No proprietary libraries

Released version 32.1 declares open-source app libraries, without a Google Play services or other proprietary runtime SDK dependency. YouTube is still a proprietary network service; operating-system components are outside this comparison.

Source

Flow · No proprietary libraries

Android 2.2.1 declares open-source runtime libraries and implements DLNA casting without Google Play services. The desktop beta also uses open-source app libraries. The GitHub flavor adds an updater and Discord integration, rather than a proprietary Discord SDK. System WebViews and remote services are outside this comparison.

Source

YouTube · No proprietary libraries

The official apps and web client use proprietary YouTube software and do not provide an auditable, fully open-source client stack. Their complete library inventory is not public. Browser playback does not require Android Google Play services.

What to check before switching

Move your library

OpenTubeX imports FreeTube .db data for subscriptions, watch history, search history, and playlists. Export the database from FreeTube, then use the matching import actions in OpenTubeX. Copy downloaded files separately; open tabs do not transfer.

Import instructions

Use more than one device

FreeTube's official app runs on desktop and stores data locally. OpenTubeX runs on desktop and Android, with an experimental iOS/iPadOS app. Its optional sync uses end-to-end encryption to protect selected data before upload.

OpenTubeX sync guide · FreeTube data storage

Offline downloads

FreeTube removed its built-in downloader in version 0.24.0 and recommends separate download tools. OpenTubeX supports video, audio, playlist, and available subtitle downloads. File formats and quality depend on the video and platform.

OpenTubeX download guide · FreeTube 0.24.0 release notes

Tabs and windows

FreeTube supports separate windows but has no browser-style tabs. OpenTubeX keeps videos and channels open in tabs within the app. Its tab organizer lets you find an open tab.

OpenTubeX tab controls · FreeTube tabs discussion
