  1. v0.31.0 Beta

    v0.31.0-betaAug 9, 2026

    Highlights

    • Upcoming premieres now refresh automatically, comments appear during premieres, and live chat has improved scrolling with optional timestamps and choosing between top chat or all messages. The chat can now be opened as a full-screen dock. Chat replays are also supported. (#490)
    • Settings now opens in a draggable, resizable window, integrated subpages, and cross-category search. The button to open them has been moved to the app header and its icon has been changed to a cog wheel. (#555, #570)
    • Added advanced video and playlist download options plus a page for managing active and completed downloads. (#351, #568)

    More improvements

    • Also show managed tool download progress in persistent notifications (like subscription refresh). (#487)
    • Show translation completion percentages and theme select menus. (#420, #482)
    • Videos about a game now show the game’s box art, title and release year in the description (#456, #486)
    • The Subscriptions page now shows the feed tabs next to the page title whenever they fit, leaving more room for the feed itself. (#483)
    • yt-dlp is now the default stream extraction method and can be selected from General settings. (#501)
    • yt-dlp downloads and playback now use the configured proxy, as do the downloads of the managed yt-dlp and FFmpeg binaries (#413, #507)
    • Show YouTube’s paid-promotion disclosure (can be disabled in Settings). (#494)
    • Added an animation speed control to Theme settings. (#491)
    • Hashtags and handles in video titles and descriptions are now clickable, even when YouTube did not link them itself (#485)
    • The player only shows the previous and next buttons when the playlist actually has a video to skip to (#481)
    • Manage and automatically apply playback speed, video quality, subtitles, and volume for individual channels with the refreshed Channel Settings. The button below the player is shown combined when multiple settings are enabled. (#536)
    • Added a setting to disable automatic Shorts looping (#538)
    • Improved SponsorBlock labels (they now match the official browser extension), submission controls, and default skip prompts (#541)
    • The chapters sidebar and fullscreen dock keep the current chapter centered while you watch (#542)
    • The Ctrl+Tab switcher now wraps into multiple rows and shows tab icons when they are enabled (#554)
    • Show an on-screen indicator when toggling Fast-Forward Through Silence with a keyboard shortcut (#528, #553)
    • Removed the separator line when using horizontal tabs (#574)
    • Video tags are now shown at the bottom of video descriptions and the description can now also be copied. (#558, #573)
    • Video thumbnails now morph into newly opened tabs. (#572)
    • You can now mark individual subscription videos as seen from their overflow menu. (#575)

    Fixed bugs

    • Fixed GitHub-style alerts and collapsible details in the in-app update changelog. (#459)
    • Show release notes for every update skipped since the installed version. (#443)
    • Fixed channel icons disappearing from restored tabs after restarting the app. (#493)
    • Fixed the video quality staying at 360p after the player fell back to the legacy formats and was switched back to the DASH formats (#497)
    • Show the video thumbnail instead of a black player while switching playback formats. (#505)
    • Fixed the fullscreen comments dock appearing empty after reloading or re-sorting the comments while scrolled down (#499)
    • Keep the thumbnail and normal player size visible when video stream recovery fails. (#508)
    • Progress notifications such as the subscription refresh no longer cover the video while watching in fullscreen (#511)
    • Fixed the player staying in Picture-in-Picture after restoring the window when several automatic PiP triggers were enabled (#492, #496)
    • Fixed the scroll mini player floating in the middle of the screen instead of staying docked in its corner after the window was resized (#498)
    • Comment sections now correctly report disabled comments and hide unavailable reply controls. (#502)
    • Stopped running the IP block recovery script when a changed IP address, rather than an IP block, made the video’s streaming URLs fail (#523)
    • The update prompt no longer repeats the version it is offering, shows collapsible sections of the release notes expanded instead of as an empty box, and links commit hashes to their commit page. (#509)
    • Fixed fullscreen Share and Add to playlist popovers appearing behind SponsorBlock notifications. (#510)
    • Improved Shorts player controls, seekbar behavior, tab switching, and loading feedback. (#495)
    • Captions now scale with the player instead of covering the whole scroll mini player, and their maximum size can be set up to 400% (#527, #532)
    • Fixed long entries cutting off the context menu’s text (#533, #535)
    • Upcoming premieres can no longer be marked as watched until they have aired (#534)
    • Videos are now automatically reloaded once when the YouTube watch session expired mid-playback (#540)
    • Fixed tab previews being cropped on the left and right when using the horizontal tab bar (#549)
    • FIxed tab bar clipping on macOS plus the hamburger still showing with the bottom nav (#551)
    • Channels and suggested videos on Shorts are now actual links (so you can open them in a new tab) (#556)
    • Fixed stretched and soft-looking images in community posts (#561)
    • Improved live chat layout and scrolling in the sidebar and fullscreen dock, including Super Chat presentation (#559)
    • Long options in select dropdowns are no longer unnecessarily truncated. (#567)
    • Pinned tab close buttons are aligned correctly in the vertical tab layout. (#571)
    • Fixed the scroll mini player replaying its entrance animation when returning to a tab. (#569)
    • Video information is now shown immediately when using yt-dlp for stream extraction, instead of waiting for yt-dlp to finish before anything appears (#580)
    • SponsorBlock hover labels now match overlapping seekbar segments. (#581)
    • Fixed the subscribed channels page failing to load when a subscription has no usable thumbnail, and tabs staying blank after a failed load instead of showing their page. (#578)

    • The icon-only chapters button in the player controls now shows whether the chapters overlay is open. (#466)
    • Channel lists with many subscriptions and the Settings page now open without long rendering delays. (#458)
    • Tab previews now show only the page content, no longer capture another tab’s preview popup, and take up roughly a third of the disk space they used to, with leftover preview files cleaned up on startup. (#469)
    • Keep custom playlist ordering responsive while videos are pending removal. (#461, #462)

    • Show a clear notice and remove stale reply controls when YouTube no longer makes advertised comment replies available. (#457)

  3. v0.30.1 Beta

    v0.30.1-betaJul 30, 2026

    Two Things Worth Knowing

    note

    OpenTubeX is now available on AlternativeTo!

    If you enjoy using OpenTubeX, please consider leaving a like. It helps more people discover the project and shows that OpenTubeX has an active user community.

    important

    In case you missed it: new distribution channels and repositories are now available.

    OpenTubeX can now be installed and updated through:

    • Windows: winget (winget install OpenTubeX.OpenTubeX)
    • Debian / Ubuntu: OpenTubeX APT repository
    • Fedora / Red Hat: COPR or the OpenTubeX RPM repository
    • openSUSE: OpenTubeX RPM repository
    • All Linux distributions with Flatpak: OpenTubeX Flatpak remote
    • Arch Linux: Officially maintained opentubex-bin and opentubex packages in the AUR

    See the installation instructions on the OpenTubeX downloads page.

    We recommend switching to one of these package-managed installation methods. Future updates can then be installed through your package manager, with no need to manually download each new release.

    More improvements

    • The thumbnail progress and toast timeout indicator is now wrapped around both rounded corners (#370)
    • Added an option to use a configurable fixed width for horizontal tabs. (#367, #380)

    Fixed bugs

    • Fixed several Shorts, playlist panel, progress indicator, PiP, history, and layout regressions. (#359, #360, #361, #362, #363, #364, #365, #366)
    • Prevented closed tabs from reappearing after shutdown and made the app window appear sooner on startup. (#369)
    • Hovering a toast now reliably freezes its timeout indicator instead of sometimes letting the line keep draining. (#373)
    • Dragging the thumbnail size slider is smooth again on pages with many videos (#372)
    • Fixed subscription feed layouts and animations, Shorts controls and watch progress, and menu layering near the tab bar. (#374)
    • Fixed the settings page jumping back to the highlighted section after switching tabs (#371)
    • Fixed the app header disappearing when opening a modal on a scrolled page. (#375)
    • The animation of the subscription feed tab indicator no longer stutters when the feeds contain a lot of videos (#378)

  4. v0.30.0 Beta

    v0.30.0-betaJul 29, 2026

    Flatpak users

    warning

    A Flatpak publishing issue temporarily caused some users to install the nightly branch instead of the stable branch.

    Check your currently installed branch with:

    flatpak info --show-ref org.opentubex.OpenTubeX

    If the output ends with /nightly, switch back to stable:

    flatpak uninstall org.opentubex.OpenTubeX//nightly
flatpak install opentubex org.opentubex.OpenTubeX//stable

    Your application data and settings should remain intact.

    Highlights

    • Added support for end-to-end encrypted synchronization of subscriptions, playlists, history, channel playback speeds, profiles, tabs and settings. An OpenTubeX instance is hosted at sync.d3sox.me (Privacy Policy). LibreTube Sync Servers are also supported but do not provide encryption or support syncing channel playback speeds and settings. The server’s source code is available here. If you want, you can self-host it too
    • Added a YouTube-style Shorts display and player that can be disabled in the theme settings (#344)
    • Added a simple watch queue. Videos can be queued from the three-dots menu. The queue appears in a side panel on the watch page where it can also be managed (#272, #275)
    • The full-screen docks can now be resized and rearranged (#279)
    • Updated the Add to playlist button to open an inline popover that lets you select which playlists the video should be added to. The notification now also shows the playlist name (#291)
    • The subscription feed refresh can now be canceled and shows new videos instantly while still loading the rest (#293, #300)
    • The New subscriptions feed now separates Videos, Shorts and Live content into dedicated sections (#347)
    • Added predefined options for downloading videos as .mp4 files, and audio downloads now always embed metadata
    • You can now multi-select tabs using Ctrl or Shift. Selected tabs can also be dragged together and closed or reloaded using shortcuts (#288, #308)
    • Added an option to restore all previously open tabs on startup
    • Tabs now display icons by default, which can be disabled in settings. Video and channel pages use the channel avatar
    • Toast notifications have a new appearance with icons, optional timeout indicators and video thumbnails. They now appear in the bottom-right corner, which is customizable, and can be dismissed by swiping them away (#294, #302, #303, #342)
    • Performance improvements for startup, scrolling, long feeds, subscription refreshes, ambient mode and tab state updates (#315)
    • OpenTubeX is now available through an APT repository, RPM repository, COPR and Winget (winget install OpenTubeX.OpenTubeX)

    More improvements

    • Added display and submission support for SponsorBlock full-video labels and mute segments (#350, #357)
    • Added a full-screen dock for video information that can be opened by clicking the title
    • Added a web search option with search engine customization to the right-click menu when selecting text (#340)
    • The system-native context menu has been replaced with a custom one that includes icons and is now translatable (#273, #340)
    • There are now chips to filter channel search results (#280, #312)
    • You can now choose an icon for your quick-bookmark playlist. When the video is in the selected playlist, the icon turns green
    • The watched percentage threshold can now be customized. Set it to 0% to restore the old behavior of marking videos as watched instantly (#277, #275)
    • Added a distraction-free setting to hide end-screen annotations (#278, #275)
    • Added a setting to open the chapters panel automatically (#267)
    • There is now an option in settings to highlight settings that differ from their defaults. It also adds a reset button for them
    • Scrollbars are now overlaid on the page instead of taking up space. They hide after a few seconds without mouse movement and can be disabled (#306)
    • There is now a setting to adjust how rounded UI elements should be, and the selected rounding is applied consistently (#314)
    • Refined the floating actions in the bottom-right corner in full-screen (#273)
    • Added clearer grouping to the single-column video action menu (#317)
    • The full search history is now shown (#271, #275)
    • When you filter a search for a term, the filters are now restored when you select its search suggestion (#270, #275)
    • Added a default shortcut of F1 to switch between horizontal and vertical tabs (#296)
    • The tab selected after closing the current tab can now be customized (#297)
    • The description now always shows the “Show less” link at the bottom instead of the X at the top-right (#298)
    • Updated the global progress bar to make it more visible (#285)
    • Updated the appearance of the video player buffering spinner (#301)
    • Added runtime version information to the About page (#284)
    • All download channels except Winget now provide a way to opt into nightly releases. See the downloads page for instructions. These builds are very likely to contain bugs and should only be used for testing (#274, #331)

    Fixed bugs

    • Fixed three Auto PiP issues (#265, #266, #268)
    • Fixed SABR recovery getting stuck in backoff loops or permanently dropping playback to 360p after repeated failures (#310, #325)
    • Active livestreams and ongoing premieres are no longer marked as watched, and background tabs no longer save unwatched videos at 0:01 (#222, #327, #295)
    • Fixed comments not loading automatically in full-screen or background tabs (#305, #307, #330)
    • Fixed comment replies becoming stuck after empty responses and missing comment avatars (#332, #292)

    • Fixed distorted seek thumbnails near the end of some videos (#334)
    • Fixed SponsorBlock and find-bar keyboard shortcut conflicts (#299, #282)
    • Fixed several responsive layout issues (#290)
